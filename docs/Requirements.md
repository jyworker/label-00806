# 微信外卖平台 - 需求文档

## 1. 项目概述

### 1.1 项目背景

本项目是一个完整的外卖点餐系统，包含用户端微信小程序和管理后台两个客户端，为用户提供在线点餐、订单管理等功能，为商家提供菜品管理、订单处理等后台管理能力。

### 1.2 项目目标

- 为用户提供便捷的外卖点餐体验
- 为商家提供高效的订单和菜品管理工具
- 实现完整的订单生命周期管理
- 支持多商家、多分类的菜品展示

### 1.3 用户角色

| 角色 | 描述 | 使用端 |
|------|------|--------|
| 普通用户 | 使用小程序浏览商家、点餐下单 | 微信小程序 |
| 管理员 | 管理商家、菜品、订单、用户 | 管理后台 |

## 2. 功能需求

### 2.1 小程序端功能

#### 2.1.1 用户认证

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 微信登录 | 通过微信授权自动登录/注册 | P0 |
| 个人信息 | 查看和修改昵称、头像、手机号 | P1 |
| 退出登录 | 清除登录状态 | P1 |

**详细说明**：
- 用户首次使用自动注册，无需填写信息
- 支持修改昵称（微信原生输入组件）
- 支持修改头像（微信原生选择头像组件）
- 手机号支持手动输入修改

#### 2.1.2 商家浏览

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 商家列表 | 展示所有营业中的商家 | P0 |
| 商家搜索 | 按名称搜索商家 | P1 |
| 商家详情 | 查看商家信息、菜品分类、菜品列表 | P0 |

**详细说明**：
- 商家列表显示：Logo、名称、评分、月销量、起送价、配送费
- 商家详情页显示菜品分类和对应菜品
- 菜品显示：图片、名称、价格、销量

#### 2.1.3 购物车

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 添加菜品 | 将菜品加入购物车 | P0 |
| 修改数量 | 增减购物车中菜品数量 | P0 |
| 删除菜品 | 从购物车移除菜品 | P0 |
| 清空购物车 | 一键清空所有菜品 | P1 |
| 切换商家 | 切换商家时自动清空购物车 | P0 |

**详细说明**：
- 购物车与商家绑定，切换商家需确认清空
- 实时计算总价和商品数量
- 显示起送价差额提示

#### 2.1.4 订单管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 提交订单 | 选择地址、填写备注、提交订单 | P0 |
| 订单列表 | 查看所有订单，支持状态筛选 | P0 |
| 订单详情 | 查看订单详细信息 | P0 |
| 订单支付 | 模拟支付流程 | P0 |
| 取消订单 | 取消待支付的订单 | P1 |
| 确认收货 | 确认配送中的订单 | P1 |
| 删除订单 | 删除已完成/已取消的订单 | P2 |

**订单状态流转**：

```
待支付(0) → 待接单(1) → 配送中(2) → 已完成(3)
    ↓
已取消(4)
```

| 状态 | 值 | 用户可操作 |
|------|----|-----------| 
| 待支付 | 0 | 支付、取消 |
| 待接单 | 1 | - |
| 配送中 | 2 | 确认收货 |
| 已完成 | 3 | 删除 |
| 已取消 | 4 | 删除 |

#### 2.1.5 收货地址

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 地址列表 | 查看所有收货地址 | P0 |
| 新增地址 | 添加新的收货地址 | P0 |
| 编辑地址 | 修改已有地址 | P0 |
| 删除地址 | 删除收货地址 | P1 |
| 默认地址 | 设置默认收货地址 | P1 |

**地址字段**：
- 联系人姓名（必填）
- 联系电话（必填，11位手机号）
- 省/市/区（可选）
- 详细地址（必填）
- 是否默认

## 3. 非功能需求

### 3.1 性能需求

| 指标 | 要求 |
|------|------|
| 页面加载时间 | ≤ 2秒 |
| API 响应时间 | ≤ 500ms |
| 并发用户数 | 支持 100+ 并发 |

### 3.2 安全需求

| 需求 | 描述 |
|------|------|
| 身份认证 | JWT Token 认证 |
| 密码加密 | BCrypt 加密存储 |
| 接口鉴权 | 管理端和用户端分离鉴权 |
| 数据校验 | 前后端双重校验 |

### 3.3 可用性需求

| 需求 | 描述 |
|------|------|
| 响应式设计 | 管理后台适配不同屏幕 |
| 加载提示 | 操作时显示 loading 状态 |
| 错误提示 | 友好的错误信息展示 |
| 空状态处理 | 列表为空时的提示 |

### 3.4 兼容性需求

| 端 | 要求 |
|----|------|
| 小程序 | 微信基础库 2.25.0+ |
| 管理后台 | Chrome、Firefox、Safari、Edge 最新版 |

## 4. 数据模型

### 4.1 用户表 (user)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT | 是 | 主键 |
| openid | VARCHAR(100) | 是 | 微信openid，唯一 |
| nickname | VARCHAR(100) | 否 | 昵称 |
| avatar | VARCHAR(500) | 否 | 头像URL |
| phone | VARCHAR(20) | 否 | 手机号 |
| status | TINYINT | 是 | 状态：0禁用 1启用 |
| create_time | DATETIME | 是 | 创建时间 |

### 4.2 商家表 (merchant)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT | 是 | 主键 |
| name | VARCHAR(100) | 是 | 商家名称 |

| address | VARCHAR(200) | 否 | 地址 |

| min_price | DECIMAL(10,2) | 是 | 起送价 |
| delivery_fee | DECIMAL(10,2) | 是 | 配送费 |
| status | TINYINT | 是 | 状态：0休息 1营业 |
| rating | DECIMAL(2,1) | 是 | 评分 |
| monthly_sales | INT | 是 | 月销量 |
| create_time | DATETIME | 是 | 创建时间 |

### 4.3 分类表 (category)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT | 是 | 主键 |
| merchant_id | BIGINT | 是 | 商家ID |
| name | VARCHAR(50) | 是 | 分类名称 |
| sort_order | INT | 是 | 排序 |
| status | TINYINT | 是 | 状态 |

### 4.4 菜品表 (dish)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT | 是 | 主键 |
| merchant_id | BIGINT | 是 | 商家ID |
| category_id | BIGINT | 是 | 分类ID |
| name | VARCHAR(100) | 是 | 菜品名称 |

| price | DECIMAL(10,2) | 是 | 价格 |

| 字段 | 类型 | 必填 | 说明 |

| user_id | BIGINT | 是 | 用户ID |
| merchant_id | BIGINT | 是 | 商家ID |
| address_snapshot | TEXT | 是 | 地址快照JSON |
| total_amount | DECIMAL(10,2) | 是 | 商品总额 |
| delivery_fee | DECIMAL(10,2) | 是 | 配送费 |
| actual_amount | DECIMAL(10,2) | 是 | 实付金额 |
| status | TINYINT | 是 | 订单状态 |
| remark | VARCHAR(200) | 否 | 备注 |
| create_time | DATETIME | 是 | 下单时间 |
| pay_time | DATETIME | 否 | 支付时间 |
| deliver_time | DATETIME | 否 | 配送时间 |
