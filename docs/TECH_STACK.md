## 架构决策记录

### ADR-001: 选择 JWT 而非 Session

**背景**: 需要实现用户认证机制

**决策**: 使用 JWT 无状态认证

**理由**:
- 支持分布式部署，无需共享 Session
- 减轻服务器存储压力
- 适合移动端和小程序场景

**后果**:
- Token 无法主动失效，需要设置合理过期时间
- Token 体积较大，需要注意传输开销

### ADR-002: 选择 MyBatis-Plus 而非 JPA

**背景**: 需要选择 ORM 框架

**决策**: 使用 MyBatis-Plus

**理由**:
- SQL 可控性强，便于优化
- 学习曲线平缓，团队熟悉度高
- 内置分页、代码生成等实用功能

**后果**:
- 需要手写部分 SQL
- 数据库迁移需要额外工具支持

### ADR-003: 选择 Redis 作为缓存

**背景**: 需要提升系统性能

**决策**: 使用 Redis 作为分布式缓存

**理由**:
- 高性能，支持多种数据结构
- 支持持久化，数据安全
- 生态成熟，运维工具丰富

**后果**:
- 增加系统复杂度
- 需要处理缓存一致性问题
