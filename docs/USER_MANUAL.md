## 管理后台使用指南

### 1. 登录系统

1. 访问管理后台地址
2. 输入用户名和密码
3. 点击"登录"按钮

默认管理员账号：
- 用户名：admin
- 密码：admin123

### 2. 数据概览

登录后进入数据概览页面，可查看：
- 今日订单数
- 今日营业额
- 总订单数
- 总营业额
- 用户总数
- 商家总数

数据每次进入页面时自动刷新，确保查看到最新的统计信息。

### 3. 商家管理

#### 3.1 查看商家列表
- 支持按商家名称搜索
- 支持按状态筛选
- 分页展示商家信息

#### 3.2 新增商家
1. 点击"新增商家"按钮
2. 填写商家信息：
   - 商家名称（必填）
   - 商家地址（必填）
   - 联系电话（必填）
   - 起送价格
   - 配送费
   - 商家图片
   - 商家描述
3. 点击"确定"保存

#### 3.3 编辑商家
1. 在商家列表中点击"编辑"按钮
2. 修改商家信息
3. 点击"确定"保存

#### 3.4 启用/禁用商家
- 点击状态开关可快速切换商家状态
- 禁用后，小程序端将不显示该商家

### 4. 菜品管理

#### 4.1 查看菜品列表
- 支持按商家筛选
- 支持按分类筛选
- 支持按菜品名称搜索

#### 4.2 新增菜品
1. 点击"新增菜品"按钮
2. 填写菜品信息：
   - 所属商家（必填）
   - 所属分类
   - 菜品名称（必填）
   - 菜品价格（必填）
   - 菜品图片
   - 菜品描述
3. 点击"确定"保存

### 5. 订单管理

#### 5.1 查看订单列表
- 支持按订单状态筛选
- 支持按日期范围筛选
- 支持按订单号搜索

#### 5.2 订单状态说明
| 状态 | 说明 |
|------|------|
| 待支付 | 用户已下单，等待支付 |
| 待接单 | 用户已支付，等待商家接单 |
| 配送中 | 商家已接单，正在配送 |
| 已完成 | 订单已完成 |
| 已取消 | 订单已取消 |

#### 5.3 处理订单
- 点击"接单"按钮接受订单
- 点击"配送"按钮开始配送
- 点击"完成"按钮完成订单

### 6. 用户管理

#### 6.1 查看用户列表
- 查看所有注册用户
- 支持按手机号搜索

#### 6.2 禁用用户
- 点击状态开关可禁用/启用用户
- 禁用后用户无法登录小程序

## 小程序使用指南

### 1. 首页

- 展示附近商家列表
- 支持搜索商家
- 点击商家进入商家详情

### 2. 商家详情

- 查看商家信息
- 浏览菜品列表
- 添加菜品到购物车

### 3. 购物车

- 查看已添加的菜品
- 修改菜品数量
- 删除菜品
- 查看订单金额
- 提交订单

### 4. 订单

#### 4.1 提交订单
1. 选择收货地址
2. 填写备注（可选）
3. 确认订单信息
4. 点击"提交订单"

#### 4.2 查看订单
- 在"我的订单"中查看所有订单
- 点击订单查看详情

#### 4.3 取消订单
- 待支付和待接单状态的订单可取消
- 点击"取消订单"按钮

### 5. 地址管理

#### 5.1 添加地址
1. 进入"我的" -> "地址管理"
2. 点击"新增地址"
3. 填写收货人、电话、地址信息
4. 点击"保存"

#### 5.2 设置默认地址
- 点击地址右侧的"设为默认"

### 6. 个人中心

- 查看个人信息
- 管理收货地址
- 查看历史订单
- 联系客服

## 常见问题

### Q1: 忘记管理员密码怎么办？
联系系统管理员重置密码，或通过数据库直接更新密码（需使用 BCrypt 加密）。

### Q2: 商家无法显示在小程序？
检查以下几点：
1. 商家状态是否为"启用"
2. 商家是否有上架的菜品
3. 网络连接是否正常

### Q3: 订单无法取消？
只有"待支付"和"待接单"状态的订单可以取消。已接单或配送中的订单需联系商家处理。

### Q4: 如何修改商家营业时间？
在商家管理中编辑商家信息，修改配送时间字段。

### Q5: 小程序登录失败？
1. 检查网络连接
2. 确认微信授权
3. 清除小程序缓存后重试
4. 联系客服处理

### Q6: 如何批量导入商家或菜品？
目前系统暂不支持批量导入，需逐个添加。如有大量数据需要导入，请联系技术支持。

### Q7: 订单数据如何导出？
在订单管理页面，设置筛选条件后点击"导出"按钮，可导出 Excel 格式的订单数据。

### Q8: 如何查看系统操作日志？
管理员可在"系统设置" -> "操作日志"中查看所有管理操作记录。

### Q9: 图片上传失败怎么办？
1. 检查图片格式（支持 JPG、PNG、GIF）
2. 检查图片大小（不超过 5MB）
3. 检查网络连接
4. 尝试压缩图片后重新上传

### Q10: 如何设置配送范围？
在商家管理中编辑商家信息，可设置配送距离或配送区域。

## 使用场景指南

### 场景一：新商家入驻

1. 登录管理后台
2. 进入"商家管理" -> "新增商家"
3. 填写商家基本信息（名称、地址、电话等）
4. 上传商家 Logo 和门店图片
5. 设置起送价格和配送费
6. 保存后进入"菜品管理"添加菜品
7. 确认无误后启用商家

### 场景二：处理用户投诉

1. 在"订单管理"中找到相关订单
2. 查看订单详情和用户备注
3. 根据情况选择：
   - 联系商家核实情况
   - 为用户退款或补偿
   - 记录处理结果
4. 在"用户管理"中查看用户历史订单

### 场景三：促销活动设置

1. 在"商家管理"中选择参与活动的商家
2. 编辑商家信息，更新配送费或起送价
3. 在"菜品管理"中调整菜品价格
4. 活动结束后恢复原价

### 场景四：数据分析

1. 进入"数据概览"查看整体数据
2. 查看今日订单数和营业额
3. 对比累计订单数和总营业额
4. 根据数据调整运营策略

### 场景五：处理异常订单

1. 在"订单管理"中筛选异常状态订单
2. 查看订单详情，了解异常原因
3. 联系用户或商家确认情况
4. 根据情况修改订单状态或进行退款
5. 记录处理过程

## 操作技巧

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl + F | 搜索 |
| Ctrl + R | 刷新页面 |
| Enter | 确认操作 |
| Esc | 取消/关闭弹窗 |

### 批量操作

- 在列表页面可勾选多条记录进行批量操作
- 支持批量启用/禁用商家
- 支持批量上架/下架菜品

### 数据筛选

- 使用组合筛选条件快速定位数据
- 筛选条件会自动保存，刷新页面后保持
- 点击"重置"清除所有筛选条件
